- 按第 7 节分阶段实施，每个阶段单独提交、单独重跑

## 2. 设计原则

1. **硬门槛只回答“分红是否可信”**，“分红质量高低”交给评分。会把好公司系统性挡在门外的门槛，要么改口径，要么降为评分。
2. **一条门槛对应一种独立风险**，不让两条门槛重复卡同一件事。
3. **阈值要有出处**：要么来自监管或会计口径，要么在规格中写明是策略选择。不使用没有依据的 0。
4. **一刀切的位置加缓冲**：门槛边界附近的公司不应因单期微小波动反复进出。

## 3. 现行规则的实测表现（20261101）

| 组合约束 | 无 | 现行规则下 Top10 有 6 家银行 |

## 4. 硬门槛重新设计

### R1 市场预筛（修正 + 缓冲）

保留五年、3%、80% 的策略口径。3% 是绝对值，不随利率变化，这是有意的策略定位，需在规格中写明。

修正每日股息率的取值：

- 分母改为**有收盘价的交易日**；
- 当日 `dv_ttm` 有值 → 直接使用；
- `dv_ttm` 为空，且截至当日过去12个月已实施现金分红为 0 → **记为 0%**（现行规则把这类日子从分母中剔除，不分红的期间因此被“免考”）；
- `dv_ttm` 为空，但过去12个月有已实施分红 → 用 TTM DPS / 收盘价 重算；
- 仍无法确定 → 记为缺失。数据充足性要求不变：至少 1000 个交易日已确定股息率，且确定率 ≥ 80%。

实现说明：Tushare 只在过去12个月没有现金分红时把 `dv_ttm` 留空。20261101 全量数据核对显示，`dv_ttm` 为空的交易日都对应过去12个月已实施现金分红为 0，第三种情形没有出现。因此实现简化为：有收盘价的交易日，`dv_ttm` 为空即记 0%；没有收盘价的交易日记为缺失。

实测：对现有 45 家通过者，按新口径计算后均仍 ≥ 80%，没有误伤；天齐锂业、万科A 这类长期停止分红的公司，其达标占比会如实降到 39%、57%。

新增缓冲（迟滞）：

- 首次入选要求 ≥ 80%；
- **上一期正式 Top10 成员**的保留线为 ≥ 75%；
- 没有上一期正式结果时不适用。上一期结果从数据根目录中日期最近的、早于本次 run-date 的正式 Top10 CSV 读取，并在审计表中记录来源。

### R2 分红记录（不变）

- 连续三年实施现金分红；
- 最新可比 DPS ≥ 前三年中位数的 70%（分红重复计数已在 `25303e0` 修复）。

### R3 支付率（不变）

- 最新支付率 0%–100%，三年平均 10%–100%。下限 10% 不起作用，作为安全网保留。

### R4 盈利韧性（放宽阈值）

- 四个年度扣非归母净利润均为正（不变）；
- **最新扣非 / 三年前扣非 − 1 ≥ −10%**（原为 ≥ 0）；
- ROE 稳定性门槛不变（沪深300 最低 80%），作为安全网。

取 −10% 的理由：能区分“正常波动”（中国石油 −5%、中信特钢 −4%、双汇 −5%、华域 −1%、浦发 −1%、宝钢 −5%）和“利润中枢下移”（中国神华 −31%、陕西煤业 −48%、大秦铁路 −47%、海螺水泥 −50%）。各阈值下的敏感性见第 6 节。

基年依赖问题并未完全消除。如果更看重这一点，备选方案是改用四年对数回归斜率 ≥ −3%/年，但它更不直观，暂不推荐。

### R7 Top10 组合约束（新增）

- 按 `stock_basic.industry`，**同一行业在 Top10 中最多 5 家**；
- 超出上限的公司保留综合得分和全量排名，状态记为 `concentration_capped`，原因注明“行业上限”，由下一名顺延；

## 5. 评分口径调整（第二阶段）

这些改动会改变分数，与第 4 节的门槛调整相互独立，建议在门槛方案上线并观察一期后再做。

| 编号 | 现行 | 提案 | 解决的问题 |
|---|---|---|---|
| S1 | DROE = 最新 TTM ROE − 上年同期 | **标准化 DROE = DROE / 自身 12 季度 TTM ROE 标准差**，各组通用 | 保险 ROE 的波动尺度是银行的数倍，平安在金融参照池中的 DROE 分位基本由涨跌方向决定 |
| S2 | DPS CAGR = 两端点 (最新/最早)^(1/4) − 1 | 五个财年可比 DPS 的**对数回归斜率** | 对端点年份过于敏感 |
| S3 | OPCFD = TTM 经营现金流 / 总负债 | TTM 经营现金流 / **有息负债**（短借 + 长借 + 应付债券 + 一年内到期非流动负债）；有息负债为 0 时取参照池最高分位 | 美的等公司的应付和合同负债反映议价能力，不是偿债压力 |
| S4 | 2.5%/97.5% 缩尾后取秩分位 | 删除缩尾（池子不超过 41 家时不起作用）；**按披露精度分档后再排名**：ROE/DROE 0.1pp，NPL 变化与 NIM 变化 0.05pp，DPS CAGR 1pp | 差异小于口径误差时，秩分位放大了噪声 |
| S5 | 连续分红年数不封顶 | 不变，但在规格中写明它测的是 **A 股可比口径**，A+H 回归股会被系统性低估 | 口径透明 |

评分分位在预筛池中计算，硬门槛只决定谁进入排名，不改变任何公司的分数。因此在预筛池不变的前提下，下表结果是精确的。R1 迟滞本期没有影响，因为没有上期 Top10 成员落在 75%–80% 之间。
