| 平均重合家数 | 8.40 | 8.38 | 7.87 |
| Top10 平均家数 | 8.6 | 8.5 | 8.0 |
| 平均年换手率 | 29% | 34% | 33% |
| 等权年化全收益（参考） | 12.0% | 12.3% | 10.5% |

同期中证红利全收益年化 8.5%，沪深300全收益 6.1%。

## 3. 按采纳标准（提案 6.4）判断

| 标准 | v2 | v2 + 周期门槛 |
|---|---|---|
| 1. 削减率不高于 v1 | 满足（25.9% ≤ 26.7%，只少 1 次） | 满足（21.2%，少 6 次） |
| 2. 权重扰动稳定性高于 v1 | 满足（重合率 98.7% 对 97.8%；2022–2025 为 99.4% 对 96.7%） | 满足（98.5%；2022–2025 为 99.0%） |

稳定性用**重合率**（重合家数 ÷ 基准 Top10 家数）比较，不用重合家数。v2 + 周期门槛排除了一部分公司，Top10 平均只有 8.0 家，重合家数自然偏少（7.87），这不代表它更不稳定。所有方案都高于提案设定的 7 家下限。

## 4. 敏感性

| 变动 | 结果 |
|---|---|
| G7 利息覆盖取 2 / 3 / 4 倍 | 削减率 26.7% / 25.9% / 27.1%，基本不变。通过其他门槛的公司本来就不缺偿债能力，G7 起保险作用 |
| 利润容差取 −5% / −10% / −15%（v2） | 26.2% / 25.9% / 25.9% |
| 利润容差取 −5% / −10% / −15%（v2 + 周期门槛） | 20.5% / 21.2% / 21.2% |
| 周期门槛取 1.5 / 2 / 2.5 倍（只用于非金融） | 15.3% / 21.2% / 23.2%。1.5 倍误伤长江电力 2021 和福耀 2016–2017，Top10 平均只剩 7.2 家 |
| 周期门槛用于所有公司（2 倍） | 削减率同为 21.2%，但 14 次排除中有 7 次是利润高速增长、后来没削减的银行（成都、江苏），误伤多 |
| 周期作为评分因子（权重 0.1 / 0.2） | 25.9% / 24.7%，作用弱 |

2 倍门槛（只用于非金融）排除了 7 次：格力 2018、华域 2018、海螺 2022、宝钢 2022、龙佰 2022、陕煤 2023 后来都削减了分红；中国石油 2025 的观察期还没走完。

## 5. 结论与局限

1. **评分结构从 v1 换到 v2，Top10 更稳定，削减率没有变差，但改善很小。** 每股分红能否守住主要取决于门槛；评分结构合理性的提升（行业中性、去掉 OPCFD 和 CV）主要体现在排名的解释力和稳定性上。
2. **能明显降低削减率的只有周期门槛。** 但"只用于非金融"是看过回测结果后才加的限定，存在过拟合风险。理由是银行利润被拨备平滑，且与提案第 1 条原则一致；但 10 年里只多避开 6 次削减，样本小。
3. 周期门槛使年化收益从 12.3% 降到 10.5%。收益不是采纳条件，只作报告。
4. ±20% 的权重扰动较温和。2016–2021 年候选通常不足 10 家，排名几乎不影响入选，这些年份的稳定性数字没有区分度。
5. B1 口径下银行没有专项门槛和质量因子。第 4 阶段补齐银行年报指标后，需要重跑并确认结论不变。
